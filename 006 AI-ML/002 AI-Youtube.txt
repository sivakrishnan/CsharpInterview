**GENERATIVE AI - AGENTIC**

**PROJECT 1: INFORMATIONAL AGENT (WEATHER API / NEWS API)**

Develop an AI agent that can decide which external API to call based on the user's request and return the result.

* User asks a natural question, e.g., "What's today's weather in Chennai?"
* The agent identifies that it needs to call the Weather API.
* Makes the request, retrieves the response, and formats the result into a user-friendly answer.
* Extend the same logic to multiple tools (e.g., News API, Dictionary API).
* Handle errors gracefully (e.g., if the API fails, respond with a fallback message).

**PROJECT 2: TRAVEL PLANNER AGENT**

Build an AI-powered travel assistant that can plan a trip for a user based on destination, budget, and duration.

* User provides input like "Plan me a 3-day trip to Bangalore under ₹10,000."
* The agent automatically breaks the task into steps: transport, accommodation, food, and sightseeing.
* Connect to APIs such as flights, hotels, and maps to gather real options.
* Combine all results into a structured daily itinerary while staying within the budget.
* Present the plan clearly so the user can follow it day by day.
