**Running a Web Application in a VM**

	It's entirely possible to run a web application in a virtual machine
	Install IIS on that VM
	Deploy your web app to that environment

	You are responsible for:

	* the OS, keeping it updated
	* Whatever apps / DLLs you install on that machine
	* Open ports, virtual network settings, etc.

**The new App Service Paradigm**

	Azure runs the servers
	You don't have control over the underlying OS or choose the hardware
	You pay for performance
	You upload your code and data
	And Azure runs it
	Easy to scale, lots of developer bells and whistles, less worries
	Similar price
